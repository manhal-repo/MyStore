# تطبيق المتجر (Android / Kotlin / AdMob)

## التشغيل
1. افتح المجلد في **Android Studio** (سينشئ Gradle wrapper تلقائيًا) ثم Run.
2. عدّل `Config.kt`: ضع `OWN_REPO_URL` = رابط مستودعك (`https://USER.github.io/REPO/repo`).
3. AdMob: بدّل المعرّفات التجريبية (`Config.kt` + `admobAppId` في `app/build.gradle.kts`) بمعرّفاتك.

## المستودعات
- مستودعك: افتراضي ومفعّل دائمًا.
- F-Droid و Tor Project و NetHunter Store: موجودة في تبويب "المستودعات" وغير مفعّلة. فعّلها بالمفتاح.
- تأكد من صحة روابطها في `Repository.kt` قبل النشر.

## الإعلانات
- بانر سفلي دائم.
- إعلان **App Open** عند فتح التطبيق، وإعلان **بيني** عند كل ضغطة "تنزيل".
- لا يظهر المتجر ولا يبدأ التنزيل إلا بعد ظهور الإعلان فعليًا وإغلاقه. عند الفشل لا يُنفَّذ شيء.

## الأمان
- يتحقق التطبيق من SHA-256 لكل APK قبل التثبيت.
- لا يتحقق حاليًا من توقيع الفهرس (`index-v1.jar`)، يعتمد على HTTPS فقط.
